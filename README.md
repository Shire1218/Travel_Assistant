# 项目概述
该项目主要面向旅游准备活动，是旅游管理的可视化系统，用户通过不同的流程，生成可视的旅游计划，并且可以对每次旅游进行整理和资金分析。使用场景为旅游前期准备活动和旅游结束的收尾环节。后续会开发配套的移动端应用，使用户可以在旅游途中使用，实现整个项目的闭环。

# 需求详解
## 计划管理
### 目的地配置
用户可以在系统中通过表单配置旅游目的地，包括目的地的名称，地址，地图坐标等。
用户可以在系统中对已配置的旅游目的地进行增删改查操作。
### 路线管理
系统对不同目的地之间的路线进行计算，得出最优路线。
用户可以在系统中对已配置的旅游路线进行增删改查操作。
### 活动管理
用户可以在系统中配置旅游活动，包括活动的名称，类型，成本，描述等。
用户可以在系统中对已配置的旅游活动进行增删改查操作。
### 关联管理
用户可以在系统中配置不同目的地之间的关联关系，包括关联的活动，关联方案等。
用户可以在系统中对已配置的关联关系进行增删改查操作。

## 计划生成
计划管理结束后，预览并生成旅游计划的pdf文件。

## 资金管理
### 资金配置
用户可以在系统中配置旅游资金，包括资金的名称，金额，类型等。
用户可以在系统中查看所有已配置的旅游资金。
用户可以在系统中删除已配置的旅游资金。
### 资金分析
用户可以在系统中查看旅游资金的分析报告，包括资金的收入，支出，余额等。

# 数据表设计
## 目的地表
| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | int | 主键，自增 |
| name | varchar(255) | 目的地名称 |
| address | varchar(255) | 目的地地址 |
| map_coord | varchar(255) | 地图坐标 |
## 活动表
| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | int | 主键，自增 |
| name | varchar(255) | 活动名称 |
| type | varchar(255) | 活动类型 |
| cost | decimal(10,2) | 活动成本 |
| description | text | 活动描述 |
## 路线表
| 字段 | 类型 | 描述 |
| --- | --- | --- |
| id | int | 主键，自增 |
| start | int | 起始目的地id |
| end | int | 结束目的地id |
| distance | decimal(10,2) | 距离 |
| time | int | 时间 |
| route | text | 路线 |
| description | text | 路线描述 |
